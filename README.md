

# AquaPure Water Refilling Station

AquaPure is a responsive business website for a fictional water refilling station. It promotes clean drinking water, water delivery, and gallon refilling services.

## Design System

### 60-30-10 Color Palette

| Percentage | Color | Hex Code | Purpose |
|---|---|---|---|
| 60% | Ice Blue | #F0F9FF | Main background |
| 30% | Deep Blue | #075985 | Headings and buttons |
| 10% | Aqua | #06B6D4 | Highlights and accents |

### Visual Style

Minimalism + Bento Grid

The design uses clean layouts, simple typography, rounded cards, and organized content sections.

### Contrast Accessibility

Body text contrast was calculated using the WCAG contrast ratio formula.

- Light mode: #475569 on #F0F9FF = 7.11:1
- Dark mode: #E2E8F0 on #020617 = 16.36:1

Both combinations exceed the WCAG AA requirement of 4.5:1 for normal text.

## Features

- Responsive mobile-first design
- Tailwind CSS styling
- Dark mode toggle
- LocalStorage theme preference
- Reusable Tailwind component classes
- GSAP page-load timeline
- Replay intro animation
- ScrollTrigger reveal animations
- Scroll progress bar with scrub
- Reduced-motion accessibility support
- Contact form layout
